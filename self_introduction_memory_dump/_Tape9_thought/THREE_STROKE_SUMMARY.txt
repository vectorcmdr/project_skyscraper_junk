## Observations

1. The formants map to ASCII: 1=D, 2=E, 3=F, 4=H, 5=K, 6=M, 7=P, 8=R
2. The 3-stroke events cluster in the latter half of the audio (4.8s - 16.0s)
3. The most common 3-stroke (KPR) always includes the highest formant (R=913 Hz)
4. The DEF pattern appears as a group of 3 consecutive events near the end
5. The active formant count sequence shows complex patterns with an ascending/descending structure at the end

## Unresolved Questions

None of the following produced readable English text:
- Direct ASCII mapping of formant combinations
- Average frequency conversion
- Time-duration Morse code
- Binary gap encoding
- Context-based 3-digit codes
- XOR combinations

## Recommendation

The data is consistent and well-structured, suggesting a real encoding is present. However, the mapping from these 3-stroke patterns to readable text requires an interpretation rule that has not yet been identified. 

Possible next approaches:
1. The DEF/KPR patterns might be the start/end markers, with other patterns encoding the message
2. The ascending/descending count sequence at the end (7,8,7,6...) might encode digits or a separate message
3. A custom mapping table might be needed (each of the 8 unique 3-stroke combinations maps to a letter)
4. The visual arrangement of the 3 strokes (their vertical positions) might encode Braille-like patterns
